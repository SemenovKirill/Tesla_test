# Кружочки занятия — Office Add-in для PowerPoint

Расставляет индикаторные кружочки на титульном слайде и разделителях этапов одной кнопкой.

## Что делает

Открываешь add-in в PowerPoint → выбираешь тип слайда (Титул / Разделитель этапа) → вводишь «Всего» и «Активная» → нажимаешь «Применить». Скрипт:

1. Находит и удаляет на текущем слайде все шейпы с именами `lesson_dot_*` и `etap_dot_*`.
2. Создаёт N новых кружочков по правилу раскладки:
   - **Титул**: до 15 точек — в один ряд; 16–30 — в два ряда; 31+ — в три ряда. Шахматка между рядами. Центр симметрии y=5.05.
   - **Разделитель этапа**: всегда один ряд, левый край первой точки на x=0.6.
3. Активной точке alpha 100% (непрозрачная), остальным alpha 35%.
4. Именует `lesson_dot_K` или `etap_dot_K` в порядке слева-направо, сверху-вниз.

## Установка (один раз)

### Шаг 1. Включить GitHub Pages

Один раз на репозиторий:

1. Зайди в репозиторий `tesla_lessons` на GitHub.
2. **Settings → Pages**.
3. Source: `Deploy from a branch`.
4. Branch: `main`, Folder: `/docs`.
5. Save. Через ~1 минуту GitHub скажет, что страница доступна по адресу `https://semenovkirill.github.io/tesla_lessons/`.

### Шаг 2. Sideload manifest.xml в PowerPoint

На каждой машине, где нужен add-in (твоя + сотрудника):

**macOS:**
1. Скачай `manifest.xml` с GitHub (или возьми из `tesla_lessons/docs/addin/manifest.xml` локально).
2. Открой PowerPoint.
3. **Insert → My Add-ins → Manage My Add-ins** (или **Get Add-ins → Upload My Add-in** в новых версиях).
4. Выбери `manifest.xml`.
5. После загрузки в ленте **Home** появится группа **Tesla Lessons** с кнопкой **Кружочки**.

**Windows:**
То же самое, тот же путь — Insert → My Add-ins → Upload My Add-in → выбрать manifest.xml.

### Шаг 3. Проверка

1. Открой свой шаблон (или новую презентацию).
2. Создай слайд из layout «01 · Титул».
3. На ленте Home → Tesla Lessons → Кружочки. Откроется панель справа.
4. Выбери «Титул», введи «Всего: 14», «Активная: 2», нажми «Применить».
5. На слайде должны появиться 14 кружочков с 2-й непрозрачной.

## Структура файлов

```
docs/addin/
  manifest.xml      — манифест add-in (загружается в PowerPoint один раз)
  taskpane.html     — UI боковой панели
  taskpane.js       — логика (Office.js + расстановка)
  taskpane.css      — стили
  assets/
    icon-16.png, icon-32.png, icon-64.png, icon-80.png, icon-128.png
```

## Обновление логики

Меняешь `taskpane.js` или `taskpane.css` → `git push` → GitHub Pages автоматически обновляется через ~1 минуту. В PowerPoint достаточно закрыть и снова открыть taskpane.

При изменении `manifest.xml` (например, иконки, имена кнопок) — нужен повторный sideload на каждой машине.

## Известные ограничения

- **Требуется интернет** — PowerPoint при открытии taskpane загружает HTML/JS с GitHub Pages. Без сети add-in не запустится.
- **API**: PowerPoint Add-in API 1.4+ (есть в современных версиях macOS/Windows/Web).
- **Текст «ЭТАП N / M»** на разделителе при 6+ этапах перекрывается кружочками — поправь руками (это отдельный текстовый элемент в шаблоне, add-in его не трогает).

## Изменить параметры раскладки

В `taskpane.js` в верху файла объект `LAYOUT` содержит все координаты, шаги, размеры точек и пороги переключения числа рядов. Меняешь там, коммитишь — обновление сразу применится.
